This section covers what docs maintainers configure on GitHub, directly or
through PRs to the private `open-telemetry/admin` repository, as opposed to the
automation in this repository ([Build](../build/)). The policy these procedures
implement is contributor-facing:
[Docs ownership](/docs/contributing/docs-ownership/).
