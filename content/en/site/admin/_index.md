This section covers what docs maintainers configure on GitHub and in the private
`open-telemetry/admin` repository, as opposed to the automation that lives in
this repository ([Build](../build/)). The policy these procedures implement,
which approvals a PR needs and who can enable auto-merge, is contributor-facing:
[Content ownership](/docs/contributing/content-ownership/).

Planned pages: repository secrets and environments; branch protection and
rulesets on `main`; bot identities and their credentials.
