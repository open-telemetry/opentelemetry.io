오픈텔레메트리 [제로 코드 계측][zero-code instrumentation]은 아래 섹션 인덱스에
나열된 언어에서 지원한다.

쿠버네티스를 사용한다면 [쿠버네티스용 오픈텔레메트리 오퍼레이터][otel-op]로
.NET, Java, Node.js, Python 또는 Go 애플리케이션에 [제로 코드 계측을
주입][inject zero-code instrumentation]할 수 있다.

  /docs/platforms/kubernetes/operator/automatic/
