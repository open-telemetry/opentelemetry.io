이 [시작하기](..) 페이지는 다음에 해당하는 개발자를 대상으로 한다:

- 소프트웨어를 개발하고 있다.
- 코드를 작성해 옵저버빌리티를 확보하는 것이 목표다.
- 사용 중인 의존성이 텔레메트리를 자동으로 생성하기를 원한다.

오픈텔레메트리가 도와줄 수 있다! 의존성을 자동으로 계측하고, 오픈텔레메트리
API로 직접 작성한 코드를 수동으로 계측하기 위해 먼저 다음 개념을 학습할 것을
권장한다:

- [오픈텔레메트리란 무엇인가?](../../what-is-opentelemetry/)
- [코드베이스에 계측을 추가하려면 어떻게 해야 하는가?](../../concepts/instrumentation/code-based/)

다른 소프트웨어에서 의존성으로 사용되는 라이브러리, 프레임워크 또는 미들웨어를
개발한다면, 텔레메트리를 자체적으로 제공하는 방법을 학습할 것을 권장한다:

- [라이브러리에 계측 기능을 내장하려면 어떻게 해야 하는가?](../../concepts/instrumentation/libraries/)

직접 시험해 볼 애플리케이션 모음을 찾고 있다면, 공식
[오픈텔레메트리 데모](/ecosystem/demo/)가 도움이 된다.

다음으로, 사용 중인 [언어](../../languages/)에 해당하는 문서를 더 자세히 살펴볼
수도 있다:

- [C++](../../languages/cpp/)
- [.NET](../../languages/dotnet/)
- [Erlang / Elixir](../../languages/erlang/)
- [Go](../../languages/go/)
- [Java](../../languages/java/)
- [JavaScript / TypeScript](../../languages/js/)
- [PHP](../../languages/php/)
- [Python](../../languages/python/)
- [Ruby](../../languages/ruby/)
- [Rust](../../languages/rust/)
- [Swift](../../languages/swift/)
