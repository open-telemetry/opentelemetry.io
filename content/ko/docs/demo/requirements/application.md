애플리케이션이 생성할 오픈텔레메트리(OpenTelemetry) 시그널과 향후 SDK 지원을
추가할 시점을 정의하기 위해 다음 요구 사항을 결정했다.

1. 지원되는 언어 중 정식 출시(GA)된 트레이스 또는 메트릭 SDK가 있는 모든 언어는
   최소 하나의 서비스 예제를 제공해야 한다.
   - 모바일 지원(Swift)은 초기 우선순위가 아니며, 위 요구 사항에 포함되지
     않는다.

2. 애플리케이션 프로세스는 언어에 독립적이어야 한다.
   - gRPC를 사용할 수 있는 경우 우선 사용하고, 그렇지 않은 경우 HTTP를 사용해야
     한다.

3. 서비스는 교체 가능한 모듈형 컴포넌트로 설계하는 것을 권장한다.
   - 개별 서비스는 여러 언어 옵션을 제공할 수 있도록 지원하고 권장해야 한다.

4. 아키텍처는 데이터베이스, 큐, 블롭(blob) 스토리지와 같은 플랫폼 범용
   컴포넌트를 통합할 수 있어야 한다.
   - 특정 유형의 컴포넌트를 요구하지는 않지만, 일반적으로 최소 하나의 범용
     컴포넌트를 포함하는 것을 권장한다.

5. 데모에 대한 사용자 부하를 시뮬레이션할 수 있도록 부하 생성기를 제공해야 한다.
