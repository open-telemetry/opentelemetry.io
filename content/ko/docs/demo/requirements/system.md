데모가 정상적으로 실행되도록 사용 환경이 다음 시스템 요구 사항을 충족하는지
확인한다.

1. 시스템은 [Docker Desktop](https://docs.docker.com/desktop)의 시스템 요구
   사항을 충족해야 하며, 그렇지 않은 경우 선호하는 클라우드 서비스를 사용할 것을
   권장한다.
2. 데모는 Linux, macOS, Windows 운영 체제(OS)에서 동작할 수 있어야 하며, 각 운영
   체제에 대한 문서가 제공되어야 한다.
