요청 흐름을 시각적으로 확인하려면 [서비스 다이어그램](../architecture/)을
참고한다.

| 서비스                                  | 언어            | 설명                                                                                                                                              |
| --------------------------------------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| [회계](accounting/)                     | .NET            | 들어오는 주문을 처리하고 모든 주문의 합계를 계산한다(mock/).                                                                                      |
| [광고](ad/)                             | Java            | 주어진 컨텍스트 단어를 기반으로 텍스트 광고를 제공한다.                                                                                           |
| [에이전트](agent/)                      | Python          | 내장된 쇼핑 도구나 MCP가 제공하는 쇼핑 도구를 사용하는 랭그래프(LangGraph) 에이전트를 통해 사용자 프롬프트를 라우팅하는 AI 어시스턴트를 제공한다. |
| [장바구니](cart/)                       | .NET            | 사용자의 장바구니에 담긴 상품을 Valkey에 저장하고 조회한다.                                                                                       |
| [챗봇](chatbot/)                        | Python          | 사용자 메시지를 에이전트 서비스로 전달하는 Gradio 기반 채팅 UI를 제공한다.                                                                        |
| [주문 처리](checkout/)                  | Go              | 사용자의 장바구니를 조회하고 주문을 준비하며, 결제·배송·이메일 알림을 조율한다.                                                                   |
| [통화](currency/)                       | C++             | 금액을 다른 통화로 변환한다. 유럽중앙은행에서 가져온 실제 환율을 사용한다. 초당 쿼리 수(QPS)가 가장 높은 서비스이다.                              |
| [이메일](email/)                        | Ruby            | 사용자에게 주문 확인 이메일을 보낸다(mock/).                                                                                                      |
| [flagd-ui](flagd-ui/)                   | Elixir          | 피처 플래그(feature flag)를 활성화·비활성화하고 편집할 수 있다.                                                                                   |
| [사기 탐지](fraud-detection/)           | Kotlin          | 들어오는 주문을 분석하고 사기 시도를 탐지한다(mock/).                                                                                             |
| [프론트엔드](frontend/)                 | TypeScript      | 웹사이트를 제공하는 HTTP 서버를 노출한다. 회원 가입이나 로그인이 필요하지 않으며, 모든 사용자의 세션 ID를 자동으로 생성한다.                      |
| [프론트엔드 프록시](frontend-proxy/)    | 엔보이(Envoy)   | 단일 포트에서 웹 스토어와 옵저버빌리티(Observability) UI의 진입점 역할을 하는 리버스 프록시이다.                                                  |
| [이미지 프로바이더](image-provider/)    | 엔진엑스(NGINX) | 프론트엔드에서 사용하는 상품 이미지를 정적으로 호스팅한다.                                                                                        |
| [카프카(Kafka)](kafka/)                 | Java            | 주문 처리 서비스를 회계 및 사기 탐지 서비스와 연결하는 메시지 큐이다.                                                                             |
| [부하 생성기](load-generator/)          | Python          | 실제 사용자 쇼핑 흐름을 모방하는 요청을 프론트엔드에 지속적으로 보낸다.                                                                           |
| [MCP](mcp/)                             | Python          | 에이전트와 다른 MCP 호환 클라이언트를 위해 모델 컨텍스트 프로토콜(MCP)을 통해 쇼핑 도구를 노출한다.                                               |
| [결제](payment/)                        | JavaScript      | 주어진 신용카드 정보로 지정된 금액을 청구하고(mock/), 트랜잭션 ID를 반환한다.                                                                     |
| [상품 카탈로그](product-catalog/)       | Go              | JSON 파일에서 상품 목록을 제공하고, 상품 검색 및 개별 상품 조회 기능을 제공한다.                                                                  |
| [견적](quote/)                          | PHP             | 배송할 상품 수를 기준으로 배송비를 계산한다.                                                                                                      |
| [추천](recommendation/)                 | Java            | 장바구니에 담긴 상품을 기반으로 다른 상품을 추천한다.                                                                                             |
| [배송](shipping/)                       | Rust            | 장바구니를 기반으로 예상 배송비를 제공한다. 지정된 주소로 상품을 배송한다(mock/).                                                                 |
| [리액트 네이티브 앱](react-native-app/) | TypeScript      | 쇼핑 서비스 위에 UI를 제공하는 리액트 네이티브 모바일 애플리케이션이다.                                                                           |
