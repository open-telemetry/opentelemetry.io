OpenTelemetry надає два підходи до інструментування PHP без програмування:

|                  | [Автоінструментування](auto/)          | [PHP Distro](distro/)                |
| ---------------- | -------------------------------------- | ------------------------------------ |
| **Встановлення** | Composer + PECL-розширення             | OS-пакунок (`deb`, `rpm`, `apk`)     |
| **Платформа**    | Linux, macOS, Windows                  | Тільки Linux                         |
| **Налаштування** | Composer автозавантаження              | Встановлення пакунку, перезапуск PHP |
| **Керування**    | Повне ручне керування                  | Готові стандартні налаштування       |
| **Найкраще для** | Гнучкі середовища, власна конфігурація | Робоче розгортання на Linux          |

## Оберіть автоінструментування {#choose-auto-instrumentation}

Використовуйте [PHP автоінструментування без програмування](auto/), коли ви:

- Вже використовуєте Composer
- Потрібно запускати на macOS або Windows
- Хочете максимальний контроль над інструментуванням та конфігурацією

## Оберіть PHP Distro {#choose-php-distro}

Використовуйте [OpenTelemetry PHP Distro](distro/), якщо:

- Ви здійснюєте розгортання в середовищі Linux і бажаєте встановити систему за допомогою менеджера пакунків (`deb`, `rpm`, `apk`)
- Вам потрібне налаштування без написання коду, без втручання в код застосунку або Composer
- Ви бажаєте отримати стандартні оптимальні для робочого середовища налаштування (експорт у фоновому режимі, виведені відрізки, OpAMP)
