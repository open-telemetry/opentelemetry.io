OpenTelemetry PHP Distro — це дистрибутив, орієнтований на робоче середовище, призначений для інструментування PHP-додатків за допомогою OpenTelemetry.

Багато PHP-середовищ важко інструментувати, використовуючи лише Composer (заблоковані хости, обмежені засоби побудови або суворі конвеєри розгортання). OpenTelemetry PHP Distro орієнтований саме на ці реалії робочого середовища:

- Встановлення через OS-пакунок (`deb`, `rpm`, `apk`)
- Перезапуск PHP-процесу
- Початок надсилання телеметрії

Для поширених налаштувань зміни коду додатку не потрібні.

## Що включено {#what-is-included}

Distro поєднує:

- Нативне PHP-розширення та завантажувач (`.so` артефакти)
- PHP runtime / bootstrap логіку
- Залежності автоінструментування для популярних бібліотек та фреймворків
- Скрипти пакування для Linux-дистрибутивів

## Ключові особливості {#key-features}

- Нативні OS-пакунки для робочих процесів `deb`, `rpm` та `apk`
- Автоматичний bootstrap та автоінструментування після встановлення
- Фонове надсилання телеметрії (без блокування)
- Виведені відрізки та автоматичне створення кореневих відрізків
- Групування URL для кореневих відрізків транзакцій
- Нативна серіалізація OTLP protobuf (немає окремого вимоги `ext-protobuf`)
- Підтримка PHP `8.1` до `8.4`

## Звʼязки з іншими проєктами OTel PHP {#relationship-to-other-otel-php-projects}

OpenTelemetry PHP Distro доповнює `opentelemetry-php` та `opentelemetry-php-instrumentation`.

- Обирайте distro, якщо вам потрібне управління пакунками, орієнтація на робоче середовище та впровадження без написання коду.
- Обирайте інструментування на базі Composer, якщо вам потрібний максимальний ручний контроль або гнучкість платформи.

## Швидкий старт {#quick-start}

1. Встановіть пакунок distro для вашої платформи (`deb`, `rpm` або `apk`).
2. Встановіть `OTEL_EXPORTER_OTLP_ENDPOINT` та `OTEL_EXPORTER_OTLP_HEADERS`.
3. Перезапустіть ваш PHP-процес і перевірте трейси у вашому бекенді.

Детальні інструкції див. у [посібнику з налаштування](getting-started/setup/).
