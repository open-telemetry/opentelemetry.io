SDK OpenTelemetry можуть генерувати власні внутрішні метрики (з використанням експериментальних [`otel.sdk.*` семантичних домовленостей](/docs/specs/semconv/otel/sdk-metrics/)), які описують поведінку SDK — наприклад, чи сервіс втрачає телеметрію, скільки часу займає експорт або чи заповнюються черги процесорів. Демонстраційна **Інфопанель Самоспостережуваності** візуалізує ці метрики через конвеєри відрізків, логів і метрик.

## Увімкнення SDK самоспостережуваності {#enabling-sdk-self-observability}

Самоспостережуваність SDK є опційною та все ще експериментальною, і її увімкнення здійснюється через конфігурацію SDK для кожного сервісу окремо. У демо, сервіси `ad`, `fraud-detection` та `kafka` увімкнули цю можливість. Інфопанель керується змінною шаблону `Service`, тому будь-який додатковий сервіс, який увімкне самоспостережуваність, зʼявляється автоматично.

## Доступ до інфопанелі {#accessing-the-dashboard}

Після запуску демо відкрийте інфопанель безпосередньо за адресою <http://localhost:8080/grafana/d/self-observability>, або перейдіть до неї зі списку інфопанелей Grafana ("Самоспостережуваність").
