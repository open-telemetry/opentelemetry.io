このセクションでは、トレーシングのための OpenTelemetry .NET の使用方法について説明します。

OpenTelemetry .NET は、ソフトウェアの動作とパフォーマンスを理解するために、テレメトリーデータ（トレース、ログ、メトリクス）を計装、生成、収集、エクスポートするための Tracing API と SDK を提供しています。
