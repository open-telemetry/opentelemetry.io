OpenTelemetry プロジェクトは、2026年 OpenTelemetry ガバナンス委員会（GC）選挙の実施をお知らせします。
立候補の締め切りは2026年10月16日 23:59 AoE です。
候補者リストは2026年10月19日に公開されます。
投票は2026年10月26日 12:00 UTC から2026年10月28日の終日 AoE（2026年10月29日 11:59 UTC）まで行われ、最終的な選挙結果は2026年10月30日に発表されます。

## 投票しましょう！ {#vote}

あなたが OpenTelemetry コミュニティの[有資格メンバー](https://github.com/open-telemetry/community/blob/12e094130fc85f8990d5c0ccf1493004848baa0f/governance-charter.md?from_branch=main#members-of-standing)であれば、ガバナンス委員会にコミュニティの意見が適切に反映されるよう、この選挙への投票をお願いします。
今回の選挙では4名が選出され、それぞれ2年の任期を務めます。

自動プロセスでは測定されないエコシステムへの貢献を行っている場合は、2026年10月23日 23:59 AoE までに[例外申請](https://github.com/open-telemetry/community/blob/12e094130fc85f8990d5c0ccf1493004848baa0f/governance-charter.md?from_branch=main#elections)を行うことで、選挙に参加できます。
すべての有資格メンバーと承認済みの例外申請者の一覧は[有権者名簿](https://github.com/open-telemetry/community/blob/03f8ce83a6443bdf74da15d5b2f24e52e337da5a/elections/2026/voters-roll.csv)をご覧ください。
承認された例外申請者は随時名簿に追加されます。

投票は2026年10月26日 12:00 UTC から2026年10月28日の終日、[Anywhere on Earth](https://en.wikipedia.org/wiki/Anywhere_on_Earth)（2026年10月29日 11:59 UTC）まで、[Helios Voting](https://vote.heliosvoting.org/helios/elections/9bad2b3c-d2df-4634-b801-a6926fdd2251/view) で受け付けています。
投票者は GitHub アカウントでサインインする必要があります。

詳細については、[OpenTelemetry 2026年ガバナンス委員会選挙](https://github.com/open-telemetry/community/blob/65ca9aa67c4790e2c39984f9356b349c87861ab8/elections/2026/governance-committee-election.md?from_branch=main)をご覧ください。

## ガバナンス委員会への参加に興味がありますか？ {#interested-in-joining-the-governance-committee}

OpenTelemetry に携わり、その成長を見届けてきた方、あるいはエンドユーザーとして OpenTelemetry をより良くする手助けをしたい方は、ぜひガバナンス委員会への立候補をご検討ください。
ガバナンス委員会の役割については、[こちらのブログ記事](/blog/2019/opentelemetry-governance-committee-explained/)や[チャータードキュメント](https://github.com/open-telemetry/community/blob/12e094130fc85f8990d5c0ccf1493004848baa0f/governance-charter.md?from_branch=main)をご参照ください。
2026年10月16日 23:59 AoE までに[候補者リスト](https://github.com/open-telemetry/community/blob/65ca9aa67c4790e2c39984f9356b349c87861ab8/elections/2026/governance-committee-candidates.md?from_branch=main)にプルリクエストを送ることで、自薦（または他薦）が可能です。
詳細な要件については、ガバナンス委員会選挙の[立候補](https://github.com/open-telemetry/community/blob/65ca9aa67c4790e2c39984f9356b349c87861ab8/elections/2026/governance-committee-election.md?from_branch=main#nominations)セクションをご確認ください。

今年任期を迎える GC メンバーに感謝の意を表します。
彼らは OpenTelemetry の成長に貢献してくださいました。
再選を希望される場合は、ぜひ立候補していただければと思います。
対象メンバーは、Alolita Sharma、Morgan McLean、Pablo Baeyens、Trask Stalnaker です。

## ご質問は？ {#questions}

選挙に関するご質問は、[community リポジトリ](https://github.com/open-telemetry/community/issues)で `@open-telemetry/otel-elections` チームをタグ付けしてイシューを作成するか、[cncf-opentelemetry-governance@lists.cncf.io](mailto:cncf-opentelemetry-governance@lists.cncf.io) にメールするか、投票期間中に緊急のアクセスの問題がある場合は [CNCF Slack](https://slack.cncf.io/) の [#opentelemetry](https://cloud-native.slack.com/archives/CJFCJHG4Q) でご連絡ください。

投票でお会いしましょう！
