こんにちは、コミュニティのみなさん！
私たちは[新しく任命されたコミュニティマネージャー](../new-community-managers/)です。
裏方での初期移行作業を開始しており、近い将来みなさんとお会いできることを楽しみにしています（KubeCon EU で会いませんか？）。
大きな力には大きな責任が伴います。プロジェクトとコミュニティの両方を拡大していく方法について、みなさんからの声をお聞きしたいと考えています。

それまでのあいだ、私たちのことを（改めて）紹介し、みなさんとつながりたいと思います！
CNCF の Slack でお気軽に声をかけてください。
現時点では、[#opentelemetry](https://cloud-native.slack.com/archives/CJFCJHG4Q) で直接メンションしてもらえます（全員に一度に連絡できる単一の @ を作成中です）。

## Reese Lee、コミュニティマネージャー {#reese-lee-community-manager}

![柔術のレッグエンタングルメントに取り組む Reese の写真](reese-lee.webp)

Austin Parker が [2022年後半に初の OTel コミュニティマネージャーとして発表された](/blog/2022/announcing-community-manager/)とき、「すごい！」と思ったのを覚えています。
その頃にはすでに、2021年11月に New Relic の OpenTelemetry エンジニアリングチームに加わって以来、約1年間プロジェクトに関わっていました。
この新しい役割が何を伴うのかすべて知っていたわけではありませんでしたが、何かがすぐにピンと来たのです。

その後数年間で、当時まだ始まったばかりの End-User Working Group を、現在の End-User SIG へと発展・成長させる手助けをしました。
どういうわけか人見知り（信じられないかもしれませんが、以前は*とても*人見知りでした！）と人前で話すことへの恐怖を克服し、KubeCon EU 2022（スペイン、バレンシア）で Collector を使ったテイルサンプリングについて初めての講演を行いました。

それ以来、さまざまなカンファレンスで OTel に関するセッションをさらに多く行い（そのうちたくさんは Adriana と一緒に！）、KubeCon NA 2022（ミシガン州デトロイト）で開催された初の OTel Unplugged や、KubeCon での OTel Observatory に取り組み、ブログ記事を書き、複数のイベントでプログラム委員として CFP をレビューし、ドキュメントに貢献し（現時点で最も誇りに思っているのは、私が作成して Sampling ドキュメント用に修正された[このベン図](/docs/concepts/sampling/)です）、コントリビューターやエンドユーザーにインタビューするなど、さまざまな活動を行ってきました。

この役割に任命されたことを大きな敬意と光栄の念とともに受け止めており（謙虚な驚きも少しあります）、この素晴らしいコミュニティとプロジェクトに誇りに思ってもらえるようにすることが私の目標です。
ちなみに、仕事以外では SF を読んだり、ホラー映画を観たり、柔術のトレーニングをしたりしています。

Slack では @Reese Lee、または [LinkedIn](https://www.linkedin.com/in/reese-lee/) で連絡してください。

## Adriana Villela、コミュニティマネージャー {#adriana-villela-community-manager}

![カピバラと自撮りする Adriana の写真](adriana-villela.webp)

もし10代の頃の自分に今の仕事を伝えたら、きっと驚いたことでしょう。
私はコンピューターに早くから触れていました。
最初の言語は BASIC で、最初のオペレーティングシステムは DOS でした。
これはすべて父のおかげです。父は引退したソフトウェアアーキテクトで、パンチカード（FORTRAN だったと思います）、C++、SmallTalk、Java、Go、Kotlin、そして引退後は Rust を使ってコーディングしてきました。
一方、熱心な Star Trek ファンだった私は宇宙船を設計したいと考え、航空宇宙エンジニアになる予定でした。
それなのに皮肉なことに、カナダ宇宙庁での夏のアルバイトでコードを書いた後、ソフトウェアが自分の将来だと決めたのです。
ネタバレ：私は産業工学の学位を取得しましたが、ソフトウェアとは直接関係なかったものの、ソフトウェア関連の授業がいくつか提供されていました。

クラウドネイティブへの道のりは長いものでした。
私はテック業界で20年間、主に大規模なエンタープライズのクローズドシステムで働いた後、OpenTelemetry にたどり着きました。
最初はオブザーバビリティプラクティスチームのマネージャーとして、その後デベロッパーアドボケイトとしてです。
最初のアドボカシーの仕事で、上司の Austin Parker が2022年に Lightstep で Ted Young と一緒に働くよう私を誘ってくれ（憧れの人への興奮もありました）、OpenTelemetry への貢献を勧めてくれました。
OTel ドキュメントへのいくつかの貢献から始め、2023年初頭に Reese と共に OTel End User Working Group の共同チェアに就任し、後に SIG に変わりました。
一緒に SIG を今日の姿、つまりエンドユーザーが互いに、そして OTel コミュニティの他のメンバーとつながれる活気ある繁栄したコミュニティへと築き上げました。
最も誇りに思った瞬間のひとつは、SIG への定期的なコントリビューターが増加し始めたときだと思います。
私たちの取り組みが確かな変化を生んでいたのです！

この数年間で、KubeCon（EU、NA、日本）、Observability Day（EU、NA）、Platform Engineering Day（NA）、複数の KCD（ポルト、ワルシャワ）、Open Source Summit（EU、NA、日本）、Cloud Native Days（ベルゲン、オーストリア）など、世界中のさまざまなクラウドネイティブイベントで OTel について講演する幸運に恵まれました。
その多くは、素晴らしい共同スピーカーで相棒の Reese と一緒でした。

だから Austin が Reese と私に OTel コミュニティマネージャーに興味がないかと尋ね、私たちが OTel を体現していると言ってくれたとき、それがどれほど光栄なことだったか言葉では表せません。
私たちの活動がコミュニティにこのように認められたことを思うと、涙が出ます。
本当に。
キャリアを通じてずっと自分の居場所を探してきましたが、OTel コミュニティがまさにそれでした。
ついに自分のテックのホームを見つけたのです。
私の OTel の相棒である Reese、そして CNCF Ambassadors の活動を通じてここ数年知り合った Julia と引き続き一緒に活動できることをとても楽しみにしています。
これからの素晴らしい数か月に乾杯！

Slack では @Adriana Villela、または私の [SNS](https://bio.site/adrianavillela) で連絡してください。

## Julia Furst Morgado、アソシエイトコミュニティマネージャー {#julia-furst-morgado-associate-community-manager}

![砂漠地帯の上空でタンデムスカイダイビングをする Julia の写真](julia-furst-morgado.webp)

2022年にテック業界に転身し、すぐにオープンソースに深く関わるようになりました。
Kubernetes のドキュメント、OpenTelemetry のドキュメント、そして CNCF 用語集に貢献しました。
私はいつも新しいことに挑戦し、自分のコンフォートゾーンの外に出ることが好きでした。
文字通り飛行機から飛び降りることもあります。
やがてその活動が、CNCF Ambassador になることについて [KubeCon + CloudNativeCon Chicago で講演](https://www.youtube.com/watch?v=rqtENN7iveQ)することにつながりました。

エコシステムで成長する中で、OpenTelemetry プロジェクトの多くの方々が私を支えてくれました。
プルリクエストをレビューしてくれたり、質問に答えてくれたり、足場を見つける手助けをしてくれました。
その支援が自信を与えてくれ、ここが人に投資するコミュニティだということを実感させてくれました。
今、この立場でコミュニティに奉仕することは、その旅路の自然な発展であり、意義ある形で恩返しする機会だと感じています。

私にとって、オープンソースは突き詰めると人がすべてです。
だからこそ、[KCD New York](https://kcdnewyork.com/) と [Cloud Native Meetup in New York](https://community.cncf.io/cloud-native-new-york-city/) を主催しています。
強力な技術エコシステムは、コードだけでなく、つながりと信頼によって支えられています。
人々が歓迎されていると感じると、一歩踏み出して主体的に取り組むようになります。
そのような場を作ることが、私の原動力です。

だからこそ、他の2人の素晴らしい女性と一緒にこの役割を担うことが、私にとって大きな意味を持つのです。
私たち3人は多くの点で異なります。
異なる文化、異なる経験、異なるテックへの道を歩んできました。
その違いが、私たちの聞き方やプロジェクトの未来についての考え方に影響を与えています。

OpenTelemetry はすべての人に役立つべきです。
初めて計装を書く人から、大規模な複雑な分散システムを管理するエキスパートまで、あらゆるレベルでプロジェクトがアクセスしやすく価値あるものでなければなりません。
多様性は、ある1つのタイプのコントリビューターやユーザーだけでなく、そうしたすべての人々について考える助けになります。

指名していただいたことに心から感謝しており、この新しい章に踏み出すことにワクワクしています。
これは責任であると同時に特権であり、このコミュニティで構築し、学び、恩返しし続ける準備ができています！
