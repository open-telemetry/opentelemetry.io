OpenTelemetry プロジェクトのメンテナー、ガバナンス委員会メンバー、技術委員会メンバーは、2023年11月6日から9日にシカゴで開催される [KubeCon NA][] に参加できることを大変嬉しく思います。

KubeCon 期間中の OpenTelemetry 関連のすべての情報をご紹介します。

## OpenTelemetry Contribfest {#opentelemetry-contribfest}

初の OpenTelemetry Contribfest として、2023年11月8日（水）午後2時30分から3時55分まで開催される [OpenTelemetry Contribfest](https://sched.co/1R2rQ) で、OpenTelemetry メンテナーと一緒にプロジェクトをより良くする活動に参加できることをお知らせします。
コントリビューションの機会は以下のとおりです。

- Collector メンテナーと一緒に、バグ修正、新機能の追加、新しい変換関数の追加に取り組みましょう。
- OTel JS メンテナーの計装ライブラリのアップデートを支援し、[セマンティック規約準拠](/docs/specs/semconv/)のテレメトリーデータを出力できるようにしましょう。

## 併催イベント {#co-located-events}

[Observability Day][] は、_クラウドネイティブオブザーバビリティプロジェクトのコラボレーション、議論、知識共有を促進する_ イベントです。
このイベントは2023年11月6日午前9時から午後5時まで開催されます。
OpenTelemetry に関するセッションも多数予定されています。

> <i class="far fa-exclamation-triangle"></i> **IMPORTANT access note**: You
> need an _in-person all-access_ pass for on-site access to **Observability
> Day**. For details, see [KubeCon registration][]. If you have a virtual
> ticket, you will be able to follow **Observability Day** through a live
> stream.

## OpenTelemetry プロジェクトブース {#opentelemetry-project-booth}

KubeCon NA の Project Pavilion にある OpenTelemetry プロジェクトブースにぜひお立ち寄りいただき、_「こんにちは！」_ とお声がけください。
運が良ければ、OpenTelemetry のグッズを手に入れられるかもしれません。

[Pavilion hours][] は以下のとおりです。

- 11月7日（火）: 午前10時30分 – 午後8時00分（午後6時00分 – 午後8時00分の KubeCrawl + CloudNativeFest を含む）
- 11月8日（水）: 午前10時30分 – 午後5時00分
- 11月9日（木）: 午前10時30分 – 午後2時30分

OpenTelemetry の導入、実装、利用に関するご意見やフィードバックをお聞かせいただくことで、プロジェクトの改善にご協力いただけます。
また、[コミュニティサーベイ][community survey]への回答もお願いしています。
いただいたコメントから適宜アクションアイテムを作成します。
KubeCon NA 後のサーベイ結果やアクションアイテムの最新情報は、CNCF の Slack インスタンスの [#otel-user-research][] をご確認ください。

## OpenTelemetry Observatory {#opentelemetry-observatory}

Project Pavilion のブースに加えて、Expo Hall にある Splunk 提供の OpenTelemetry Observatory にもぜひお立ち寄りください！
ここは、OpenTelemetry コミュニティメンバーやメンテナーが主導する、カジュアルなチャット、ミートアップ、その他のディスカッションの場です。
ディスカッションやショートプレゼンテーションの主催に参加されたい方は、[コンテンツ応募フォーム](https://forms.gle/ajNv8jGs12coDUjG8)にご記入いただき、ご関心をお知らせください。

OpenTelemetry について聴き、学び、参加しましょう。

シカゴでお会いしましょう！
