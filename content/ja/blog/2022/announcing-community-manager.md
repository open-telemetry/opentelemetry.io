OpenTelemetry は2019年の発足以来、大きな成長を遂げてきました。
Google のキャンパスや Zoom を通じて集まった少数の OpenTracing と OpenCensus のメンテナーやコラボレーターから始まったプロジェクトは、今や CNCF で Kubernetes に次いで2番目に人気のあるプロジェクトに成長しました。
[5400人を超えるコントリビューターと700社を超える企業](https://opentelemetry.devstats.cncf.io/d/74/contributions-chart?orgId=1&var-period=m&var-metric=contributions&var-repogroup_name=All&var-country_name=All&var-company_name=All&var-company=all&from=now-3y&to=now-2d)がコード、イシュー、ドキュメント、そしてかけがえのないフィードバックを提供してきました。

しかし、私たちのコミュニティはこれらのコントリビューターだけで構成されているわけではありません。
エンドユーザー、パートナー、インテグレーター、そのほか多くの方々が OpenTelemetry コミュニティを構成しています。
より幅広いエンドユーザーコミュニティのニーズに応えるために、ガバナンス委員会はこの大きく成長し続ける人々のグループのニーズに注力できるコミュニティマネージャーの役割を設けました。

コミュニティマネージャーはガバナンス委員会によって任命され、コントリビューターおよびエンドユーザーコミュニティの公的なスチュワードとして活動します。
イベントの企画、コントリビューター体験を向上させるための SIG や WG 間の横断的な取り組みの調整、ソーシャルメディアにおける OpenTelemetry のプレゼンス管理、そして OpenTelemetry コミュニティ全体の育成と成長に取り組みます。
つまり、これは OpenTelemetry コミュニティそのものをプロジェクトとする新しいプロジェクトメンテナーということです。

それを踏まえて、私が OpenTelemetry プロジェクト初のコミュニティマネージャーに任命されたことをお知らせできることをうれしく思います！
元 OpenTracing メンテナーとして、ウェブサイトなどのプロジェクトへの取り組み、OpenTelemetry Tuesdays のホスティング、OpenTelemetry Community Day などのイベント企画の支援を通じて、発足以来 OpenTelemetry に携わってきました。
この新しい役割において、KubeCon/CloudNativeCon の一環として世界各地で OpenTelemetry Community Days をより正式に確立し、さらに OTel Unplugged のような新しいエンドユーザーおよびコントリビューター向けイベントの推進にも取り組む予定です（詳細は1週間ほど後にお知らせします）。

次のステップは何でしょうか。
皆さんのご要望をぜひお聞かせください！
GitHub のコミュニティディスカッションに[スレッド](https://github.com/open-telemetry/community/discussions/1203)を立てましたので、コミュニティの取り組みやプログラムに関する質問、コメント、提案をお寄せいただければ幸いです。
これは OpenTelemetry のエンドユーザーに限った話ではありません。
既存および新規のコントリビューター体験の向上にどのように貢献できるかもお聞かせください！

他の方法で連絡を取りたい場合は、[Twitter](https://twitter.com/@austinlparker) または [Cloud Native Community Slack](https://cloud-native.slack.com/archives/CJFCJHG4Q) で私を見つけることができます。
