KubeCon 期間中の OpenTelemetry 関連のすべての情報をご紹介します。

この投稿は他のアクティビティの通知を受け次第更新される可能性がありますので、KubeCon の直前にもう一度ご確認ください！

## OpenTelemetry Observatory {#opentelemetry-observatory}

Expo Hall にある Splunk 提供の OpenTelemetry Observatory にぜひお立ち寄りいただき、_「こんにちは！」_ とお声がけください。
ここは OpenTelemetry コミュニティメンバーやメンテナーが主催する、カジュアルなチャット、ミートアップ、その他のディスカッションの場となります。
アクティビティスケジュールについては [OTel Observatory Calendar](https://shorturl.at/qEUX1) をご覧ください。

ディスカッションや短いプレゼンテーションのリードとして参加をご希望の方は、[OpenTelemetry End User Working Group](https://cloud-native.slack.com/archives/C01RT3MSWGZ) までご連絡ください。

OpenTelemetry の導入、実装、利用に関するご意見やフィードバックを共有いただくことで、プロジェクトの改善にご協力いただけます。

フィードバックセッションへの参加は、以下からオンラインでご予約ください。
時間はすべて中央ヨーロッパ時間（CET）です。

- **March 20th, 11:45-12:45:**
  [End User Feedback Session - .NET & .NET Auto-Instrumentation](https://calendly.com/euwg-user-feedback-session/end-user-feedback-session?month=2024-03)
- **March 20th, 15:00-16:00:**
  [End User Feedback Session - JavaScript](https://calendly.com/euwg-user-feedback-session/end-user-feedback-session-javascript?month=2024-03)
- **March 21st, 11:00-12:00:**
  [End User Feedback Session - Semantic Conventions](https://calendly.com/euwg-user-feedback-session/end-user-feedback-session-semantic-conventions?month=2024-03)
- **March 21st, 14:30-15:30:**
  [End User Feedback Session - Comms (website, docs)](https://calendly.com/euwg-user-feedback-session/end-user-feedback-session-comms?month=2024-03)
- **March 21st, 15:00-16:00:**
  [End User Feedback Session - Profiling](https://calendly.com/euwg-user-feedback-session/end-user-feedback-session-profiling?month=2024-03)
- **March 21st, 15:30-16:30:**
  [End User Feedback Session - Client-side](https://calendly.com/euwg-user-feedback-session/end-user-feedback-session-client-side)

各 SIG メンテナー1名に対して最大5名の参加者がフィードバックを提供します。
セッションは録画され、[OTel YouTube channel](https://youtube.com/@otel-official) に投稿されます。

いただいたコメントから、必要に応じてアクションアイテムを作成します。
結果やアクションアイテムのアップデートについては、KubeCon EU 終了後に CNCF の Slack インスタンスの [#otel-user-research][] をご確認ください。

ご好評につき、OTel Observatory で [Humans of OTel インタビュー](/blog/2023/humans-of-otel/)の録画を再び実施します。
OpenTelemetry の実践者やメンテナーとしての経験を共有したい方は、[インタビューセッションにサインアップ](https://calendly.com/otel-euwg/humans-of-otel)してください。

ぜひお越しいただき、OpenTelemetry について聴いて、学んで、参加してください。

パリでお会いしましょう！
